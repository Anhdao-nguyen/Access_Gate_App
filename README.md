# 🚪 Access Gate System

Modern access control and visitor management system for factory gates.

## 🚀 Quick Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/access-gate-app)

### 1. Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_REPO_URL
git push -u origin main
```

### 2. Deploy to Vercel
1. Go to [vercel.com](https://vercel.com)
2. Click "Add New Project"
3. Import your GitHub repository
4. Click "Deploy"

**That's it!** Your app will be live in ~2 minutes.

## 📱 Features

- ✅ **Dashboard** - Overview and quick actions
- ✅ **New Request** - Create visitor requests
- ✅ **Check-in Console** - Gate security interface
- ✅ **All Requests** - Monitor and manage all requests
- ✅ **User Profile** - Role-based access control
- ✅ **Quick Navigation** - Fast page switching
