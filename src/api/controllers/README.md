# Controllers
This directory acts as the **Brain** of your API.

- **What goes here?**: Functions that handle the logic when a user requests something.
- **Example**: `checkInUser`, `getGuestList`.
- **Naming Rule**: `[Resource]Controller.js` (e.g., `GuestController.js`, `AuthController.js`).

If you have a bug where the *logic* is wrong (e.g., Guest is saved but with wrong time), look here.
